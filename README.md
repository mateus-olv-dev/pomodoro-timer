# Pomodoro Timer

Um cronômetro Pomodoro simples, desenvolvido na semana 10 no Include Alura.

## 📖 Sobre o projeto

O **Pomodoro Timer** implementa a técnica de gerenciamento de tempo Pomodoro, permitindo alternar entre três contextos:

- **Foco** — período de concentração em uma tarefa;
- **Descanso curto** — pequena pausa entre os ciclos de foco;
- **Descanso longo** — pausa mais longa após alguns ciclos completos.

O usuário pode iniciar, pausar e retomar a contagem regressiva, com o tempo sendo exibido no formato `MM:SS`.

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação da interface;
- **CSS3** — estilização e layout responsivo;
- **JavaScript (Vanilla JS)** — lógica do cronômetro, manipulação do DOM e controle de eventos.

## ⚙️ Funcionalidades

- Alternância entre os contextos de foco, descanso curto e descanso longo;
- Início, pausa e retomada da contagem regressiva a partir do mesmo botão;
- Exibição do tempo restante formatado em minutos e segundos (`MM:SS`);
- Zeragem/reinício do cronômetro ao trocar de contexto.

## 🧠 Conteúdos aprendidos

Durante o desenvolvimento deste projeto, foram praticados e consolidados os seguintes conceitos:

- **Manipulação de eventos com `addEventListener`**
- **Controle de estado assíncrono com `setInterval` e `clearInterval`**
- **Uso de `switch/case`**
- **Manipulação do DOM**
- **Formatação de tempo em segundos para o formato `MM:SS`**
- **Boas práticas de organização de funções**
- **Debug de escopo de variáveis**

## 🛠️ Como executar

1. Clone o repositório;
2. Abra o arquivo `index.html` em seu navegador;
3. Escolha o contexto desejado (foco, descanso curto ou descanso longo);
4. Clique no botão de iniciar/pausar para controlar a contagem.
